# Learning Touch: AI for Visuo-Tactile Manipulation

MSc research project exploring whether tactile feedback improves learning-based robotic grasp-and-transport when vision and robot-state information are already available.

## Research Question

To what extent does adding tactile feedback to visual and robot-state observations improve task success and robustness during robotic grasp-and-transport?
